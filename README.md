# proposal-writer 스킬 — 사용 설명서

한글(HWP/HWPX) 양식에 맞춰 제안서·보고서·예산근거를 자동으로 써주는 스킬입니다.
이 문서 하나면 처음 쓰는 사람도 바로 시작할 수 있습니다.

---

## 1. 이 스킬이 하는 일 (한 문장)

> **양식과 데이터를 주면 → 조사하고 → 출처를 교차검증하고 → 양식 서식 그대로 한글 파일로 조립해서 줍니다.**

사람이 직접 하면 며칠 걸리는 "자료조사 → 초안 → 팩트체크 → 한글 서식 맞추기"를 자동으로 합니다.

---

## 2. 어떻게 만들어졌나 (구조)

이 스킬은 **5명의 에이전트가 이어달리기**하는 파이프라인입니다. 각 단계는 앞 단계 결과를 받아 자기 일을 합니다.

| 순서 | 에이전트 | 하는 일 |
|---|---|---|
| ① | 양식 분석가 | 준 양식에서 제목·본문·표 스타일을 읽고, 한글이 자주 깨지는 부분(내어쓰기·표 음영·글자 깨짐)을 미리 고침 |
| ② | 조사원 | 항목별로 웹에서 최신 자료(1차 출처 우선)를 조사해 초안 작성 |
| ③ | 검증관 | 조사원 초안을 **의심하고 반박** — 수치가 실제 출처로 뒷받침되는지, 계산이 맞는지, 가짜 링크는 없는지 확인해 교정 |
| ④ | 조립공 | 검증된 내용을 한글(hwpx) 스킬로 양식 서식 그대로 조립(표·차트·출처 포함) |
| ⑤ | 서식 검사관 | 완성본을 원본 양식과 대조 — 서식·문체·품질 게이트를 통과해야 완성 처리 |

**핵심 설계 3원칙**
1. **양식 먼저** — 양식 없이 임의 서식으로 만들지 않음. 없으면 먼저 물어봄
2. **서식 교차검증** — 결과물을 원본 양식과 대조해서 확인
3. **출처 교차검증** — 조사 초안을 그대로 쓰지 않고 검증관이 팩트체크한 것만 채택

에이전트는 따로 설치할 게 없습니다. 스킬 파일(`proposal-writer.skill`) 안에 전부 들어 있습니다.
(한글 조립 도구인 `hwpx.skill`만 함께 설치하면 됩니다 — 배포 패키지에 같이 들어 있음)

---

## 3. 설치 (한 번만)

1. Claude 데스크톱 앱에서 **Cowork** 작업을 시작
2. 대화에 `hwpx.skill` 첨부 → 저장
3. 대화에 `proposal-writer.skill` 첨부 → 저장
4. 확인: 새 대화에서 "제안서 작성해줘"라고 쳤을 때 **양식 파일을 먼저 물어보면** 정상

> 저장 옵션이 안 뜨면(조직 설정), 두 파일을 첨부한 채로 "이 스킬대로 진행해줘"라고 해도 동작합니다.

---

## 4. 준비물 (요청할 때 첨부)

| 준비물 | 필수 | 설명 |
|---|---|---|
| **양식 파일** | ✅ | 서식의 기준이 될 한글 HWP/HWPX. 기존 문서를 이어 쓸 때는 그 문서 자체 |
| **데이터** | ✅ | 작성 대상(엑셀·PDF·텍스트). 과제 목록·항목 정보 |
| **기준문서** | 선택 | 검증관이 우선 대조할 권위자료(정밀 단가표·기존 확정본 docx 등) |

## 5. 예시 프롬프트 (실제 사용 사례 기반)

아래는 실제로 이 도구를 만들며 나왔던 요청들을, 일반 사용자가 바로 쓸 수 있게 정리한 것입니다.
**굵은 부분만 본인 상황에 맞게 바꾸면** 됩니다.

### 예시 A — 처음부터 여러 과제 예산근거 쓰기 (가장 기본)
```
이 양식으로 제안서 작성해줘.
- 양식: [한글 파일 첨부]
- 데이터: [엑셀 첨부]  (과제명·담당기관·예산·산출근거가 들어 있음)
목차는 투자 필요성 → 필요 물량 산정 근거 → 단가 산정 근거 → 예산 분배 → 유사사례 순서로,
1·2번은 개괄식으로 짧게, 3번 단가만 상세하게 써줘.
100억 이상 과제만 유사사례를 넣고, 문장 끝 마침표는 빼고 개조식으로.
```

### 예시 B — 필요 물량·단가를 구체적으로 (수치·출처 강화)
```
필요 물량과 단가 근거를 구체적으로 써줘.
"대학·아파트 단지 몇 개소를 대상으로, 대상당 얼마씩" 처럼 실제 개소 수와 단위 단가를
웹에서 조사해서 출처까지 붙이고, 각 문장은 개조식으로 나눠줘.
```

### 예시 C — 기준문서로 교차검증까지 (팩트체크 강화)
```
이 문서도 참고해서 교차검증 단계까지 진행해줘.
- 기준문서: [정밀 단가표 docx 첨부]
내가 만든 초안의 수치·출처를 이 문서와 웹으로 대조해서, 틀린 예산 귀속이나
가짜 링크는 바로잡아줘.
```

### 예시 D — 표·그래프·이미지 넣기
```
예산 분배랑 유사사례는 문장 말고 실제 표로 넣어줘.
표 헤더는 회색 음영으로, 투자 필요성 섹션에는 관련 통계 그래프도 넣고,
PDF에서 뽑은 관련 그림도 필요 물량 근거 아래에 넣어줘.
```

### 예시 E — 기존 한글 문서에 꼭지만 추가 (원본 보존)
```
이 문서를 이용해서 "[추가할 주제]"에 대한 꼭지를 추가해줘.
- 문서: [한글 파일 첨부]
기존 내용·그림·표는 그대로 두고, 문서 끝에 소제목으로 넣어줘.
[안전 / 인프라 / 제도 / 운영] 4개 영역으로 나누고 마지막에 요약표랑 출처를 붙여줘.
```

### 예시 F — 다른 종류 제안서 (분야·목차 바꾸기)
```
이 양식으로 [스마트시티 공모 제안서] 작성해줘.
목차는 추진 배경 → 사업 목표 → 세부 추진 계획 → 소요 예산 → 기대 효과 5개로,
소요 예산은 연도별 표로 넣어줘.
```

### 예시 G — 서식만 다시 맞추기 (내용 유지)
```
내용은 그대로 두고 이 새 양식에 맞춰 다시 조립해줘.
- 새 양식: [한글 파일 첨부]
```

## 6. 결과물과 확인

- 완성되면 한글(.hwpx) 파일과 함께 **검증관이 고친 내역 요약**을 줍니다
- 모든 결과물은 품질 게이트(구조 검증 + strict 검사 + ID 중복 0)를 통과한 것만 전달됩니다
- 한글에서 열어 확인하고, 고칠 부분("표 너비 조정해줘", "이 영역 더 자세히" 등)을 말하면 이어서 수정합니다

---

## 7. 자주 겪는 상황

| 상황 | 이렇게 하면 됩니다 |
|---|---|
| 양식을 안 줬는데 시작함 | 도구가 먼저 "양식을 달라"고 물어봅니다. 첨부하면 진행 |
| HWP 파일만 있음 | 그대로 첨부하세요. 자동으로 HWPX로 변환 후 진행 |
| 한글에서 파일이 안 열림 | 게이트를 통과한 최신본인지 확인. 도구가 만든 파일은 통과 전 전달 안 됨 |
| 내어쓰기·표 음영이 안 보임 | 양식 분석 단계가 자동 보정. 결과 보고에서 "보정 n건" 확인 |
| 수치가 의심됨 | 기준문서를 함께 주면 검증관이 우선 대조해 교정 |
| 작업 중 한도에 걸림 | 조사·검증 결과는 저장되므로, 이어서 요청하면 조립부터 재개 가능 |

---

## 8. 팁

- **한 번에 완벽하게 시키려 하지 말고** 초안을 받은 뒤 "1·2번은 더 짧게", "단가만 상세히"처럼
  다듬어 가는 게 빠릅니다 (실제 사용도 이렇게 진행됨)
- **기준문서가 있으면 꼭 주세요.** 검증 품질이 크게 올라갑니다 (실제로 예산 오귀속·가짜 링크를 잡아냄)
- **새 세션**에서 시작할 땐 `proposal-writer.skill`·`hwpx.skill`을 다시 첨부하거나, 이미 설치돼 있으면
  바로 "제안서 작성해줘"로 시작하면 됩니다
